# Сайт рекордов Legend of Gerald на GitHub

Как это работает:

1. Игрок проходит игру и вводит имя в финале.
2. Игра создаёт в твоём репозитории issue с заголовком `run: Имя — 12:34`.
3. GitHub Actions сам проверяет результат, дописывает его в `data/results.json` и закрывает issue.
4. Сайт на GitHub Pages читает `data/results.json` и показывает таблицу. Он обновляется каждые 30 секунд.

От отправки до появления на сайте проходит около минуты. Свой сервер не нужен.

---

## 1. Создай репозиторий

1. Зайди на github.com, нажми **New repository**.
2. Имя: `legend-of-gerald` (можно любое).
3. Выбери **Public**. GitHub Pages бесплатно работает только для публичных репозиториев.
4. Нажми **Create repository**.

## 2. Загрузи файлы сайта

1. В новом репозитории нажми **uploading an existing file**.
2. Перетащи туда `index.html` и папки `data`, `img`, `scripts` из «сайт рекордов». Файл `record.yml` и этот файл тоже можно загрузить, они не мешают.
3. Нажми **Commit changes**.

## 2б. Добавь робота, который записывает результаты

Без этого шага результаты не будут записываться.

1. В репозитории нажми **Add file → Create new file**.
2. В поле имени файла напиши ровно `.github/workflows/record.yml`. Слэши сами превратятся в папки.
3. Открой `record.yml` из «сайт рекордов» в Блокноте, скопируй всё и вставь на GitHub.
4. Нажми **Commit changes**.

## 3. Включи сайт

1. Открой **Settings → Pages**.
2. В **Source** выбери **Deploy from a branch**.
3. Ветка `main`, папка `/ (root)`, нажми **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/legend-of-gerald/`.

## 4. Создай токен для игры

Токен — это ключ, которым игра создаёт issue от твоего имени. Дай ему минимум прав.

1. Открой **Settings** своего профиля (не репозитория) → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Name: `legend-of-gerald game`. Expiration: на сколько хочешь, например 1 год.
3. Repository access: **Only select repositories** → выбери `legend-of-gerald`.
4. Permissions → Repository permissions → **Issues: Read and write**. Больше ничего не включай.
5. Нажми **Generate token** и скопируй его. Он начинается с `github_pat_`.

## 5. Впиши данные в игру

В `готовый проект/config.py`:

```python
GITHUB_REPO = "ТВОЙ-ЛОГИН/legend-of-gerald"
GITHUB_TOKEN = "github_pat_...."
GITHUB_BRANCH = "main"
```

Когда эти поля заполнены, игра отправляет результаты на GitHub, а не на Flask-сервер.

## Проверка

- Пройди игру (или запусти финал) и введи имя. В игре появится место и строка «появится на сайте через минуту».
- Открой вкладку **Actions** в репозитории. Там должен быть зелёный запуск «Записать результат».
- Через минуту результат появится на сайте.

## Если что-то не так

| Что видно | Что сделать |
|---|---|
| В игре «токен GitHub не подходит или истёк» | Создай токен заново (шаг 4) |
| «у токена нет права Issues: write» | У токена не включено Issues: Read and write |
| «репозиторий не найден» | Проверь `GITHUB_REPO` (логин/имя) и что токен выдан на этот репозиторий |
| Issue создаётся, но не закрывается | Проверь шаг 2б (файл `.github/workflows/record.yml`). Открой Actions и посмотри ошибку. Если там ошибка прав: Settings → Actions → General → Workflow permissions → **Read and write permissions** |
| Issue закрыт с текстом «пропущено» | Issue создал не владелец репозитория — такие результаты не принимаются |
| Нет интернета | Игра сохранит результат и отправит его при следующем запуске |

## Безопасность

- Токен лежит в файлах игры, поэтому дай ему только право Issues на один репозиторий (шаг 4). Даже если его достанут, он сможет только создавать issue.
- Результаты принимаются только от issue, созданных твоим аккаунтом, то есть через токен игры. Чужие issue закрываются без записи.
- Имя очищается: максимум 16 символов, только буквы, цифры, пробел и `_ - . !`. Время должно быть от 10 секунд до 100 часов.
- Чтобы удалить чей-то результат, отредактируй `data/results.json` прямо на GitHub.
